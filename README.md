# حارس البطارية الذكي (Battery Guard AI) — v1.0.0

## البناء والتثبيت
1. افتح المجلد في Android Studio (Koala أو أحدث) واترك Gradle يزامن (يحتاج إنترنت مرة واحدة لتنزيل الاعتماديات).
2. وصّل Galaxy S24 Ultra (تصحيح USB) ثم Run، أو: Build > Build APK(s).
3. من سطر الأوامر بعد المزامنة: ./gradlew assembleDebug  (ملف APK في app/build/outputs/apk/debug).
4. الاختبارات: ./gradlew test

## ما نُفِّذ
لوحة تحكم بقياسات حقيقية، مراقبة دورية (WorkManager) مع قاعدة Room، جلسات شحن، مراقبة حرارة، تقدير سعة موضّح،
محلل إحصائي (انحراف الاستهلاك، استنزاف الخمول، حرارة، شحن ليلي) بتوصيات (مشكلة/دليل/سبب/إجراء/ثقة)،
أتمتة (5 أنواع محفزات، إشعار + سجل)، إشعارات عربية، مرصد التطبيقات (UsageStatsManager)، اختصارات Samsung مع بدائل،
أوضاع الطاقة (تغيّر فترة القياس)، سجل ومقارنات، تصدير CSV، حذف البيانات، RTL، وضع داكن/فاتح.

## أُضيف في التحديث الثاني
تصدير PDF، نافذة زمنية للقواعد (ترحيل Room 1→2)، ارتباط التطبيقات بالتفريغ، تقرير شهري تلقائي، gradle-wrapper.properties (شغّل `gradle wrapper` أو دع Android Studio ينشئه).

## القيود والفروقات (بصراحة)
- لم يُبنَ APK ولم يُختبر على جهاز: بيئة التنفيذ بلا Android SDK ولا Gradle ولا إنترنت. الكود لم يُترجم بعد؛ توقّع إصلاح أخطاء ترجمة بسيطة.
- خطوط Cairo / Noto Naskh غير مضمّنة (لا إنترنت). ضع ملفات .ttf في res/font وطبّقها في Typography.
- معظم نصوص الواجهة داخل Kotlin وليست في strings.xml.
- الإعدادات في SharedPreferences بدل DataStore. لا ترحيل Room (الإصدار 1).
- لا نموذج تعلم آلي، ولا نسخ احتياطي منفصل (CSV وPDF للتصدير فقط). PDF نصي بسيط وقد تحتاج مراجعة شكل العربية على الجهاز.
- جداول ThermalRecords/BatteryHealthRecords/AppUsageRecords/EnergyReports مدمجة في BatterySamples أو محسوبة آنيًا.
- القياس كل 15 دقيقة كحد أدنى (قيد WorkManager)، فتنبيهات الشحن/الأتمتة غير لحظية.
- السعة التصميمية ونسبة الصحة، واستهلاك الطاقة لكل تطبيق، وإيقاف الشحن برمجيًا: غير متاحة لتطبيق عادي.
- ربط التطبيقات بالتفريغ ارتباط زمني فقط وليس إثبات سبب.
